# 縣有地租約連動工具

比對「承租人一覽表」和「縣有農牧用地清冊」這兩個 Excel 檔。工具會依地號把承租人姓名、租約期間同步到資料較舊的那一邊，並產生差異報告。

主力版本是**單一 HTML 檔**：雙擊就用瀏覽器開啟，不必安裝、不需要網路，資料只在本機瀏覽器處理，不會上傳。

## 下載

到 [Releases](../../releases) 下載 `縣有地租約連動工具.html`。exe 是給 HTML 不能用時的備用版。

## 使用方式

1. 用 Edge 或 Chrome 開啟 `縣有地租約連動工具.html`
2. 選擇或拖入兩個 `.xlsx`：承租人一覽表、縣有農牧用地清冊
3. 選「只比對」或「比對＋產生同步後的檔案」，按「開始」
4. 下載差異報告，以及同步後的兩份 Excel

**原檔不會被修改。** 同步後的檔案另外存成新檔，改過的儲存格塗淺紫色底，註解裡記錄原值與日期。

## 判斷規則

- **配對鍵**：鄉鎮＋段＋小段＋地號。比對前會先正規化：
  - 去掉「市／鄉／鎮」「段」字尾
  - 地號統一成 `0000-0000`，例如 `1732`、`1732-0000` 都會轉成同一格式
  - 去掉「內」字
  - 修正常見的異體字
- **方向**：比較兩邊的最晚到期日，以到期日較晚的一邊為準。
  - 承租表較新：更新清冊的「使用關係人」「租約起訖」
  - 清冊較新：回寫承租表的「租約期間」。只限單一承租人、而且姓名相同的情況
- **不自動改、只列在報告裡的情況**：
  - 使用關係是「租用、占用」等混合型
  - 欄位裡夾帶說明文字
  - 承租表註記「到期未續」
  - 姓名不同但看不出哪邊較新

差異報告有以下工作表：

| 工作表 | 內容 |
|---|---|
| 總覽 | 各類筆數 |
| ① 承租表較新→改清冊 | |
| ② 清冊較新→改承租表 | |
| ③ 需人工確認 | |
| ④ 清冊租用但無租約 | |
| ⑤ 承租表地號清冊查無 | 會附上清冊中同名承租人，方便找地號打錯的那筆 |
| ⑥ 承租表有約但清冊非租用 | |

## 檔案格式假設

- **承租人一覽表**：
  - 工作表名稱以「承租人總表」開頭
  - 第 1 列是表頭，要有這些欄：承租人、鄉鎮、段名、小段、地號、承租範圍、租約期間、租約到期未續
- **縣有農牧用地清冊**：
  - 前 5 個工作表是各所清冊
  - 前 5 列內要有這些表頭：鄉鎮市（或鄉鎮）、段、小段、地號、使用關係、使用關係人、租約起訖
  - 各工作表的欄位位置可以不同，工具會依表頭名稱找欄

## 專案結構

```
html_src/
  lease_core.js     比對與同步核心（瀏覽器與 Node 共用）
  template.html     介面
  build.py          組成單檔 HTML → 縣有地租約連動工具.html
  vendor/           ExcelJS 4.4.0（MIT）
lease_sync.py       Python 版（同一套規則，可打包成 exe）
```

## 開發

修改 HTML 版：

```bash
cd html_src
python build.py
```

使用 Python 版：

```bash
pip install openpyxl
python lease_sync.py 承租人一覽表.xlsx 縣有地清冊.xlsx --sync
```

打包 exe：

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name 縣有地租約連動工具 --exclude-module numpy --exclude-module pandas lease_sync.py
```

改了比對規則時，`lease_core.js` 和 `lease_sync.py` 兩邊都要一起改。

**真實資料含身分證、電話、住址，不要提交到本倉庫。** `.gitignore` 已經排除所有 `.xlsx`。
